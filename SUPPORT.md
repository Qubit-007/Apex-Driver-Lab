# Support

## Getting help

- Review [README.md](README.md) for setup and usage.
- Review [TRAINING.md](TRAINING.md) for training and checkpoint guidance.
- Search existing GitHub issues before opening a new question or bug report.

For reproducible defects, use the bug report template. Include the command, operating system, Python version, and relevant error output. Do not attach model checkpoints, secrets, or unrelated personal data.

This is a community-maintained project. Support and response times are not guaranteed.
